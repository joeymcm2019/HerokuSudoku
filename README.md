# HerokuSudoku

A browser-based Sudoku game.

Use Node.js 20.19+ within the 20.x release line, or Node.js 22.12 or later.

```sh
npm ci
npm run dev
```

Open the URL printed by Vite. `npm start` also starts the development server.

Run `npm run build` to generate the production site in `dist/`. Run
`npm run preview` to check the built site locally.
